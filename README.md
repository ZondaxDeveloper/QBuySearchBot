# QBuySearch 🤖🛍️

QBuySearch es un bot de Telegram que te ayuda a buscar productos en Amazon de diferentes países usando SerpAPI y enlaces de afiliado personalizados. Devuelve resultados con imágenes, precios y descripciones.
---

## 🚀 Características

- 🔎 Busca productos escribiendo `buscar <producto> /place <mx|es|us|...>`
- 🌐 Soporte multilenguaje: español, inglés, francés
- 🔁 Cambia de idioma con `/setlang <es|en|fr>`
- 📌 Mensaje guía anclado automáticamente al iniciar
- 💸 Enlaces con tu código de afiliado de Amazon

---

## 🛠️ Requisitos

- Python 3.8 o superior
- Cuenta de Telegram con un bot creado vía BotFather
- Clave de SerpAPI: [https://serpapi.com](https://serpapi.com)
